# Attention-au-rhume

Un rhume non traité peut s'aggraver.
Quand vous êtes enrhumé, reposez-vous, buvez beaucoup d'eau et consultez un médecin si les symptômes persistent au-delà de quelques jours.
Repos : votre corps a besoin de repos pour mieux se défendre.
Boire de l’eau : cela aide à fluidifier les sécrétions et à soulager les symptômes.
Consultez un médecin si les symptômes deviennent inhabituel ou persistent au-delà de quelques jours.
