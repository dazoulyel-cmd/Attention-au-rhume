# Attention-au-rhume

Un rhume non traité peut s'aggraver.
Quand vous êtes enrhumé, reposez-vous, buvez beaucoup d'eau et consultez un médecin si les symptômes persistent au-delà de quelques jours.
Reposez-vous — Votre corps a besoin de repos pour mieux se défendre.
Buvez beaucoup d'eau — Cela aide à fluidifier les sécrétions et à soulager les symptômes.
Consultez un médecin — Si les symptômes persistent au-delà de quelques jours.
